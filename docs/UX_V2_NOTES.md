# UX/UI V2 — presentation layer

Документ для синхронизации команды. Менялся только UI; Simulation Engine, датасет и формула Score не трогались.

## Принцип

Сначала смысл → затем показатели → затем технические коды (T1, M7…).

Язык: «модельная Астана», «синтетическая модель».

## Что изменилось для пользователя

1. Человеческие названия метрик + «Эффект через N кварталов» вместо «лаг».
2. Score в UI с 2 знаками (52,56 → 56,54; +3,99).
3. Районные меры: «Выберите район», без авто-Есиль; городские — «Весь город».
4. Sticky-статус бюджета и 5/5 на экране решений.
5. Навигация экранов: изучить / принять решения / последствия.
6. Карточки районов по направлениям с раскрытием показателей.
7. Результат: крупный Score до→после и блок «Почему изменился Score?» из ответа движка.
8. Карта: подписи, раздельные легенды score vs critical, дельты на результате.
9. Профили районов из `frontend/src/data/district-profiles.json`.
