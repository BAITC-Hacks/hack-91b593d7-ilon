# Дополнительные возможности

Кратко для команды: что появилось поверх основного демо-пути. Официальная формула Score и `simulate` не менялись.

## Возможности

| # | Возможность | Как пользоваться |
| ---: | --- | --- |
| 9.1 | Сравнение сценариев | Вкладка «Оспорить план» → после challenge side-by-side |
| 9.2 | Шепли | Вкладка «Вклад мер» → `POST /api/v1/shapley` |
| 9.3 | Экспорт | Кнопки Markdown / Печать в шапке результата |
| 9.4 | Учебные события | Вкладка «События»; официальный Score не меняется |
| 9.5 | История команды | Вкладка «История»; localStorage |

## API

```bash
curl -s -X POST http://127.0.0.1:8000/api/v1/shapley \
  -H 'Content-Type: application/json' \
  --data-binary @backend/examples/scenario.json
```

Frontend proxy: `/api/shapley` (таймаут до 60 с).

## Важно для защиты

- Не называть challenge/Шепли «глобальным оптимумом».
- События — «учебное допущение», не часть официальной формулы.
- Основной демо-путь 3–5 мин по-прежнему: город → пример → рассчитать → оспорить → совет.
