# Демо 3–5 минут — «Аким на 5 часов»

Цель: показать CALCULATE → UNDERSTAND → CHALLENGE → LEARN → DECIDE без терминала (кроме запуска). Числа берёт движок; в UI не хардкодить итоги. Источник контрольных решений — кнопка **«Пример сценария»** (= [`backend/examples/scenario.json`](../backend/examples/scenario.json)).

## Перед защитой

```bash
docker compose down
docker compose up --build --detach --wait --wait-timeout 120
```

Открыть http://localhost:3000 (или `WEB_PORT`, если задан). Режим `demo` — без API-ключа.

Регрессии (по возможности перед выходом на сцену):

```bash
cd backend && .venv/bin/python -m pytest -q
cd ../frontend && npm run lint && npm run typecheck && npm run build
```

В CI то же делает GitHub Actions (Compose + Playwright).
