# Демо 3–5 минут — «Аким на 5 часов»

Цель на защите: CALCULATE → UNDERSTAND → CHALLENGE → LEARN → DECIDE.  
Числа считает **движок**. AI только объясняет. Не хардкодить Score в UI.

Контрольный набор = кнопка **«Пример сценария»** (= [`backend/examples/scenario.json`](../backend/examples/scenario.json)).

## Перед выходом на сцену (обязательно)

```bash
cd /Users/yerbol/Documents/akim-ai   # или клон репозитория
docker compose down
docker compose up --build --detach --wait --wait-timeout 120
```

Открыть http://localhost:3000.

| Режим AI | Когда | Что сказать жюри |
| --- | --- | --- |
| **openai** | есть корневой `.env` с `AI_PROVIDER=openai` и ключом | «Совет — живая модель; Score посчитан отдельно» |
| **demo** | без ключа | «Программная демонстрация протокола совета; математика та же» |

Проверка за 10 секунд:

```bash
curl -s http://localhost:8000/health
# ожидаем "status":"ok" и ai_provider demo|openai
curl -s -X POST http://localhost:8000/api/v1/simulate \
  -H 'Content-Type: application/json' \
  --data-binary @backend/examples/scenario.json | python3 -c "import sys,json;d=json.load(sys.stdin);print(d['score_after'], d['spent'])"
# ожидаем 56.54307  95
```

## Сценарий на сцене (держитесь этого тайминга)

| Время | Действие | Что сказать | Ожидание |
| --- | --- | --- | --- |
| **0:00–0:35** | Экран **Город** | «Модельная Астана, бюджет 100, пять решений, горизонт 8 кварталов.» Клик по Нуре / слабый район. | Score **52,56**; **2** критических |
| **0:35–1:20** | **Решения** → «Пример сценария» | «Цены фиксированы; движок сам режет недопустимые планы.» | `5/5`, **95/100** |
| **1:20–2:10** | «Рассчитать» | «Score считает движок по официальной формуле, не нейросеть.» Показать прирост и риски справа. | **52,56 → 56,54** (~**+3,99**) |
| **2:10–3:00** | «Оспорить мой план» (вкладка) | «Поиск — одна замена среди допустимых планов, не глобальный оптимум.» | **M5 Сарыарка → M3 Нура**; **56,54 → 57,21**; видны потери метрик |
| **3:00–4:00** | «Слушать совет» | «Три роли комментируют уже посчитанный сценарий. AI не меняет Score.» | Режим openai или demo; 3 оценки + ответы; Score сверху не пропадает |
| **Финал (10 с)** | | «Решение остаётся за человеком. Модель показывает компромиссы.» | — |

Язык: «состояние модельного города», «правила синтетической модели».  
Не говорить: «решили проблемы Астаны», «AI нашёл лучший план города».

## Если что-то ломается на сцене

| Симптом | Что делать |
| --- | --- |
| Нет «Сервер подключён» | `docker compose ps`, подождать / `docker compose up --build` |
| Совет красный / timeout | Score уже на экране — сказать это и идти дальше |
| Нет вкладки challenge | На результате внизу вкладка **«Оспорить план»** |
| Порты заняты | `WEB_PORT=3100 API_PORT=8100 docker compose up --build` |
