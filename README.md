# AQYL — «Аким на 5 часов»

Учебный AI-симулятор управления городом команды **ILON**. Пользователь распределяет общий бюджет **100 условных единиц**, выбирает **ровно пять** инициатив и видит, как они меняют показатели пяти условных районов Астаны.

Основной backend работает с синтетическим датасетом организаторов: **5 районов, 10 показателей, 14 мероприятий**. Цена каждой меры фиксирована. Движок учитывает лаг, районный или городской охват, синергии и несовместимости. Сервер отклоняет превышение бюджета и другие недопустимые сценарии до расчёта и вызова AI.

Astana Quality of Life Score вычисляет детерминированный движок:

`Score = 0,7 × средняя оценка по населению + 0,3 × оценка слабейшего района − число показателей ниже 40`

AI и демонстрационный совет получают готовый расчёт и объясняют компромиссы. Их текст не влияет на Score. Данные относятся к учебной модели и не являются прогнозом реальных городских последствий.

| Контрольный расчёт | База | Пример пяти решений |
| --- | ---: | ---: |
| Расходы | 0 | 95 |
| Средняя оценка по населению | 56,8624 | 58,0776 |
| Оценка слабейшего района | 49,18 | 52,9625 |
| Критических показателей | 2 | 0 |
| **Score** | **52,55768** | **56,54307** |

В репозитории есть FastAPI backend, диагностическая страница Next.js, Docker Compose и автоматические проверки. Страница подтверждает связь с сервером и показывает данные каталога; игровой интерфейс с выбором мероприятий относится к следующему этапу.

## Запуск приложения

Нужны Git и запущенный Docker с Compose v2. Из корня репозитория:

```bash
docker compose up --build
```

Для демонстрационного режима `.env` и API-ключ не нужны. После запуска откройте приложение на http://localhost:3000, документацию API на http://localhost:8000/docs. Проверки доступности: http://localhost:3000/health и http://localhost:8000/health. На диагностической странице должны появиться статус подключения, режим AI, версия датасета, пять районов и четырнадцать мероприятий.

Для запуска в фоне с ожиданием готовности и остановки:

```bash
docker compose up --build --detach --wait --wait-timeout 120
docker compose ps
docker compose down
```

Если порты заняты: `WEB_PORT=3100 API_PORT=8100 docker compose up --build`. Внутреннее соединение контейнеров остаётся на `backend:8000`.

## Локальная разработка

Для backend нужен Python 3.12; для frontend — Node.js 24. Версии указаны в `.python-version` и `.nvmrc`. Backend, первый терминал:

```bash
cd backend
python3.12 -m venv .venv
.venv/bin/python -m pip install --require-hashes -r requirements-dev.txt
AI_PROVIDER=demo .venv/bin/python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Frontend, второй терминал:

```bash
cd frontend
npm ci
npm run dev
```

Next.js по умолчанию обращается к `http://127.0.0.1:8000`. Если адрес backend другой, укажите `API_INTERNAL_URL` в окружении команды `npm run dev` или в `frontend/.env.local`. Корневой `.env` используется backend и Compose, но не загружается Next.js автоматически. Для реального совета создайте корневой `.env` по `.env.example`, укажите `AI_PROVIDER=openai`, `OPENAI_API_KEY` и доступную вашему проекту модель `OPENAI_MODEL`. Ключ остаётся на сервере. Полный совет выполняет шесть запросов; работа с реальным ключом ещё не проверена.

## API и проверки

`GET /api/v1/catalog` отдаёт официальный каталог, правила, базу и контрольный сценарий. `POST /api/v1/simulate` принимает пять решений и возвращает Score с полным расчётом по районам. `POST /api/v1/council/stream` принимает тот же формат и возвращает объяснения совета потоком NDJSON. Запросы и запуск backend описаны в [backend/README.md](backend/README.md).

Frontend предоставляет диагностические маршруты `/api/health` и `/api/catalog`, которые обращаются к backend через серверные прокси. Если backend недоступен, страница показывает ошибку и кнопку повторного запроса. Игровые POST-маршруты пока не подключены к интерфейсу.

Из `backend/` проверки выполняются командами `.venv/bin/python -m pytest -q`, `.venv/bin/ruff check app tests` и `.venv/bin/ruff format --check app tests`. Для frontend — `npm run lint`, `npm run typecheck` и `npm run build` из `frontend/`. GitHub Actions запускает backend, frontend и интеграционные проверки при push в `main`.

Зависимости Python закреплены с SHA-256 хешами в `backend/requirements.txt` и `backend/requirements-dev.txt`; frontend использует `package-lock.json` и `npm ci`. Исходные данные и формула: [DATASET_AND_RULES.md](docs/DATASET_AND_RULES.md). Прежняя модель и формула сохранены в [архиве](docs/BACKEND_PROTOTYPE.md). Дальнейшие этапы: [ROADMAP.md](docs/ROADMAP.md).
